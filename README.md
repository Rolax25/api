# API Siloe

API para la aplicación Siloe - Contenido espiritual diario

## 📋 Datos que entrega

- ✅ Versículos del día
- ✅ Reflexiones cortas
- ✅ Santos del día (con fotos)
- ✅ Datos curiosos "Sabías que..."

## 🚀 Instalación

```bash
# Clonar el repositorio
git clone <tu-repositorio>

# Instalar dependencias
npm install

# Iniciar en modo desarrollo
npm run dev

# Iniciar en producción
npm start
